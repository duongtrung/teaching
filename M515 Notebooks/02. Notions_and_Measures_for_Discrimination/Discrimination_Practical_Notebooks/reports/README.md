# Guided results and student work

`EXECUTION_REPORT.json` records verification of guided cells. `ENVIRONMENT.json` records numerical/notebook libraries. `VALIDATION_REPORT.json` records data, schema and case-map checks. These are verification metadata, not a completed student final project.

Students should save their protocol, derived tables, figures and report in `C1/`, `C2/`, `C3/` or `C4/`. Keep project changes separate from immutable classroom raw data. Disabled student extension functions must be implemented before a final-project run.
