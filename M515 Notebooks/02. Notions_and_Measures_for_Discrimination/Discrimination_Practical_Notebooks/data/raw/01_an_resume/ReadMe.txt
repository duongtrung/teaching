README for
"Measuring Gender and Racial Biases in Large Language Models"


All figures in this manuscript can be replicated using the "Code.do" file in this folder. Please save the code and data files in the same folder.

Stata/MP 16.0 is used to run the codes.

User-written commands need to be installed:
reghdfe
resize

For figures 3 and 4, we manually store the estimated results to separate data files,
based on which we plot the figure.
